# AutoFlex — интернет-магазин автозапчастей

Витрина на Next.js 16 (App Router), React 19, TypeScript и Tailwind CSS 4.
Структура страниц повторяет ddaudio.com.ua, визуальный стиль — брендбук AutoFlex
(цвета, шрифты Inter + Exo 2, кнопки, поля, паттерны). Язык интерфейса — украинский.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm start          # запуск собранной версии
npm run lint
```

Нужен Node.js 20.9 или новее.

## Что настроить перед запуском в продакшен

| Что | Где |
| --- | --- |
| Телефон, e-mail, график, мессенджеры, соцсети | `src/lib/site.ts` |
| Реквизиты продавца для оферты и политики конфиденциальности (сейчас заглушки) | `src/lib/site.ts` → `legal` |
| Порог бесплатной доставки (`0` — доставку всегда оплачивает покупатель) | `src/lib/site.ts` → `freeDeliveryFrom` |
| Адрес сайта для canonical, sitemap и Open Graph | `.env.local` → `NEXT_PUBLIC_SITE_URL` |
| Куда приходят заказы и заявки | `.env.local` → `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` и/или `ORDER_WEBHOOK_URL` |

Скопируйте `.env.example` в `.env.local` и заполните. Без канала уведомлений заказы в режиме
разработки печатаются в терминал, а в production оформление заказа возвращает ошибку —
чтобы ни один заказ не потерялся молча.

Тексты оферты и политики конфиденциальности — типовые шаблоны, их стоит показать юристу.

## Каталог и подключение поставщика

Сейчас каталог — детерминированные демо-данные:

- `src/data/categories.ts` — 12 групп и 58 категорий;
- `src/data/brands.ts`, `src/data/makes.ts` — производители, марки и модели авто;
- `src/data/product-templates.ts` + `src/data/products.ts` — генератор товаров;
- `src/data/reviews.ts` — демо-отзывы.

Все страницы читают каталог только через функции `src/lib/catalog.ts` (поиск, фильтры,
фасеты, подбор по авто). Чтобы подключить прайс или фид поставщика, достаточно наполнить
те же структуры (`Product`, `Brand`, `Make`, `CarModel` из `src/lib/types.ts`) реальными
данными или заменить реализацию функций в `catalog.ts` на запросы к базе или API.

Фотографии товаров: положите ссылки в `product.images` и разрешите хост изображений в
`next.config.ts` (`images.remotePatterns`). Пока фотографий нет, показывается линейная
иллюстрация категории из `public/illustrations`.

## Как устроен проект

```
src/app                  маршруты: главная, каталог, товар, подбор по авто, бренды, поиск,
                         корзина, оформление, избранное, кабинет, акции, блог, инфо-страницы,
                         API (заказ, заявка, поиск, товары по id), sitemap.xml, robots.txt
src/components/ui        кнопки, поля, модальное окно, панель, табы, карусель, пагинация…
src/components/brand     логотип и фирменная графика
src/components/product   карточка товара и её части
src/components/listing   листинг с фильтрами, сортировкой и пагинацией (состояние в URL)
src/components/layout    шапка, мега-меню, поиск, мини-корзина, мобильная навигация, подвал
src/lib                  типы, каталог, форматирование, клиентское хранилище, настройки магазина
src/data                 демо-данные каталога, статьи блога, акции, FAQ
src/app/globals.css      дизайн-токены и базовые классы
```

Корзина, избранное, выбранное авто, просмотренные товары и данные кабинета хранятся в
браузере покупателя (localStorage).

## Что не входит в текущую версию

Серверные учётные записи покупателей, онлайн-оплата, API «Новой Почты» (выбор отделения из
справочника), синхронизация остатков и цен с поставщиком. Способы оплаты и доставки
покупатель выбирает в форме заказа, а менеджер подтверждает заказ вручную.
